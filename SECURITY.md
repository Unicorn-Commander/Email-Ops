# Security policy

Please do not report vulnerabilities in a public issue or discussion. Use [GitHub private vulnerability reporting](https://github.com/Unicorn-Commander/Email-Ops/security/advisories/new) for this repository and include:

- the affected commit or deployment context;
- concise reproduction steps;
- the impact and any required privileges; and
- a safe way to follow up.

Do not include live credentials, private mail content, or usable tokens in a report. If private vulnerability reporting is unavailable, contact the repository maintainers through an authenticated private channel before disclosing the issue publicly.
